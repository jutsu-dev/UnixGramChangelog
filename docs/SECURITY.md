# Безопасность

- Секреты хранятся только в `.env`, менеджере секретов сервера или GitHub Secrets.
- `.env` исключён из Git. В репозитории остаётся только `.env.example`.
- Конфигурация принимает ровно один ID владельца в `ADMIN_IDS`.
- Middleware молча отбрасывает сообщения и callback-запросы не от владельца.
- Управление разрешено только в личном Telegram-чате владельца.
- Источник не может публиковать напрямую: между обнаружением и каналом есть очередь проверки.
- HTML формируется с экранированием динамических значений.
- Контейнер работает без root, Linux capabilities и повышения привилегий.
- Файл production-окружения принадлежит root и имеет режим `600` или `400`.
- GitHub Actions используют закреплённые commit SHA сторонних actions.

Об уязвимости сообщайте приватно владельцу проекта. Не публикуйте токены, персональные данные и рабочие exploit-примеры в открытом issue.
