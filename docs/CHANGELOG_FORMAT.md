# Формат записей

| Тип | Тег | Когда использовать |
|---|---|---|
| ✨ Новая функция | `#feature` | появилась новая возможность |
| 🎨 Интерфейс | `#interface` | изменились экран, навигация или визуал |
| 🛠 Исправление | `#fix` | устранена подтверждённая ошибка |
| ⚙️ Техническое | `#technical` | инфраструктура, производительность, внутреннее поведение |
| 🧪 Эксперимент | `#experiment` | функция тестируется или доступна части пользователей |
| 🔎 Обнаружено | `#discovery` | найдено скрытое или ещё не объявленное изменение |
| 🔌 API | `#api` | контракт, endpoint или схема данных |
| 📱 Клиент | `#client` | изменение приложения или платформы |
| 🚨 Важное | `#important` | изменение требует внимания большинства пользователей |

Запись отвечает на три вопроса: **что изменилось**, **кому это важно**, **где подтверждение**. Каждая запись описывает одно изменение. Дата и версия показываются только тогда, когда они известны точно.

Пример:

```text
✨ Поиск по подаркам

В каталоге появился поиск по названию коллекции и номеру подарка.

Новая функция · #feature

источник: UnixGram

#UnixGramChangelog
```
