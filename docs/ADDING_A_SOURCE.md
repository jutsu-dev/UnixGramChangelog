# Новый источник

1. Создайте модуль в `src/unixgram_changelog/sources/`.
2. Реализуйте протокол `ChangeSource` и метод `collect()`.
3. Преобразуйте результат в `Detection(ChangeEntry(...), confidence, evidence)`.
4. Используйте стабильный `external_id`, если источник его предоставляет.
5. Добавьте fixture и тесты для нормального, пустого и повреждённого ответа.

Источник обязан иметь короткие таймауты, ограниченные повторные попытки и не должен менять внешнее состояние. Ошибка одного источника не останавливает остальные.
