# Участие в проекте

Перед изменениями откройте issue с коротким описанием задачи. Для кода используйте отдельную ветку и небольшой pull request.

```bash
python -m venv .venv
.venv/Scripts/activate
python -m pip install -e ".[dev]"
ruff check .
mypy src
pytest -q
```

Новый источник должен иметь тесты, стабильный идентификатор изменений и ссылку на проверяемое доказательство. Не добавляйте секреты, cookies и реальные пользовательские данные.
