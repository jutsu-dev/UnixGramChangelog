# Участие в проекте

Репозиторий используется как закрытый production-проект. Внешние pull request и публичные форки не предполагаются.

Изменения вносятся только владельцем или по его прямому согласованию.

```bash
python -m venv .venv
.venv/Scripts/activate
python -m pip install -e ".[dev]"
ruff check .
mypy src
pytest -q
```

Новый источник должен иметь тесты, стабильный идентификатор изменений и ссылку на проверяемое доказательство. Не добавляйте секреты, cookies и реальные пользовательские данные.
