# Безопасность

Не публикуйте сведения об уязвимости в открытом issue. Свяжитесь с владельцем проекта через [UnixGram History](https://t.me/unixgramhistory) и приложите краткое описание, способ воспроизведения и возможное влияние.

Токены, cookies, пароли и пользовательские данные не должны попадать в issue, pull request или логи CI. Подробности о модели безопасности проекта находятся в [docs/SECURITY.md](docs/SECURITY.md).
